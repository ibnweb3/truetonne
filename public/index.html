How it works

01 · Read

Pull out the claims

The AI step only extracts. Any project ID or tonne figure it returns that is not written in your text is dropped, and you see why.

02 · Match

Match against the registry

Each claim is matched to retirement records that name the claimant. A retired tonne can back only one claim, so overlaps show up as a gap.

03 · Record

Lock the tonnes on-chain

Recording the report on Base Sepolia gives each backing retirement to the claimant. If another party already holds those tonnes, the contract refuses and logs a blocked double claim.
